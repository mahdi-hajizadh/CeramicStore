# CeramicStore Web

React + Vite storefront for CeramicStore.

## Scripts

```bash
npm install
cp .env.example .env
npm run dev
npm run build
npm run lint
```

## Environment

| Variable | Description | Default |
|----------|-------------|---------|
| `VITE_API_URL` | Backend origin | `http://localhost:5158` |

## Routes

- Store: `/`
- Admin: `/admin`
- Owner: `/owner`
